# E-Commerce Intelligence & Analytics Platform

A portfolio-quality Data Analytics project for analyzing
e-commerce sales, customers, products, profitability,
returns, discounts, and business performance.

## Project Goal

Build an end-to-end analytics pipeline that transforms
raw e-commerce data into actionable business insights.

## Core Technologies

- Python
- Pandas
- NumPy
- SQL
- PostgreSQL / Supabase
- Power BI
- Scikit-learn
- AI-assisted insights
- Resend
- GitHub Actions
